# Barn

"Barn" 现在提供了一个使用 [Ursina](https://www.ursinaengine.org/) 游戏引擎编写的 3D 无尽跑酷游戏 —— **Neon Drift Runner**。

## 游戏简介

- **类型**：3D 无尽跑酷（类似热门游戏《Temple Run》）
- **玩法**：角色会自动向前奔跑，通过键盘在三条赛道间切换、跳跃以躲避障碍物。
- **特点**：
  - 随机生成的霓虹色障碍。
  - 逐渐提升的奔跑速度和得分。
  - 碰撞后显示最高成绩，可按 `R` 立即重新开始。

## 环境准备

1. 建议使用 Python 3.9 及以上版本。
2. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

   **提示**：首次安装 Ursina 会自动拉取 Panda3D，下载体积较大，请耐心等待。

## 运行游戏

```bash
python -m game.main
```

### 操作说明

| 操作        | 对应按键             |
|-------------|----------------------|
| 开始/跳跃   | `Space`（空格）      |
| 左移        | `A` 或 `←`            |
| 右移        | `D` 或 `→`            |
| 重新开始    | `R`                  |
| 退出游戏    | `Esc`                |

游戏启动后角色会自动向前奔跑，尽可能长时间躲避障碍物以取得高分！
